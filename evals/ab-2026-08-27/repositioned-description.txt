Vet and load agent skills from the public ecosystem — the open catalog beyond whatever is already installed or provided by the user's organisation. Use when a search of installed or built-in skills comes back empty and the work still needs tooling it does not have, when the user names a repository, author, or skill and wants it found, judged, or vetted as safe to run, or when they ask to extend what the agent can do. Reads what a candidate actually instructs and checks its source before recommending anything, then offers a choice between installing it permanently and loading it for a single session. Not for authoring, listing, or removing the user's own skills.
